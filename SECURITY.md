# Security Policy

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository and include:

- the affected command, service, or UI flow;
- steps to reproduce the issue;
- the expected impact; and
- relevant macOS, Rust, Tailscale, and Network Manager versions.

This project discovers local-network devices and can construct or launch SSH
commands. Never include real credentials, private keys, access tokens, or a
complete private-network inventory in a report.
