# Network Manager UI V3 Iteration Prompt

Iterate the V2 glass design into a more restrained Apple/macOS glass look.

## Direction

The current V2 is too flashy. Reduce visual noise and make it feel like a real Apple productivity utility.

## Must improve

- Less neon, less saturated blue/green glow.
- More Apple-like glass/material: subtle translucency, graphite/tinted sidebar, restrained highlights.
- Correct component spacing and alignment everywhere.
- Rows, cards, badges, buttons, and status groups must sit on a consistent 8px spacing scale.
- Fix clipped, cramped, or visually unbalanced components.
- Use native macOS proportions: compact controls, calm toolbar, clear sidebar, clean inspector.
- Keep status colors but use them sparingly: dots/badges, not large glowing blocks.

## Screen-specific

1. Dashboard
   - Make table/card spacing precise.
   - Align columns and action buttons.
   - Reduce glow behind rows.
   - Make summary strip calm and native.

2. Discovery
   - Filters should look like macOS filter chips/segmented controls, not web buttons.
   - Source badges should be quieter.
   - Rows should have consistent vertical rhythm.

3. Device Detail
   - Inspector should feel like a macOS side panel.
   - Endpoint groups need balanced internal padding.
   - Merge/split actions should be visually secondary.

4. Quick Access Popover
   - Most important: should look like an Apple menu bar popover.
   - Less flashy, tighter, beautiful spacing, subtle material.
   - Rows should be easy to scan and actions aligned.

5. Settings
   - Native grouped settings form.
   - Quiet controls, clear labels, good footnote spacing.

## Deliverable

Create a new V3 Pencil file from the input. Preserve existing V1/V2 input as reference only. Export preview PNG.
